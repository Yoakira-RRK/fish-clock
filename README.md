# fish-clock 小鱼钟

按时刻表让 AI 主动开口的 DSH 插件。

官方自带的主动消息插件是「固定间隔 + 概率命中」：每 N 分钟掷一次骰子，掷不中就不发，也不补。结果是**有时候等半天也等不到**，而「没说话」被当成了正常。

小鱼钟把随机性挪了个位置：**发不发是确定的，几点几分是随机的。**

## 行为

- **固定窗口**：每天 `09:30–10:00`、`14:00–14:30`、`19:30–20:00` 各一次，窗口内随机挑一分钟，命中率 100%。
- **额外次数**：`09:00–23:00` 之间再随机 1~2 次，避开固定窗口前后 N 分钟，两次之间至少隔 15 分钟。
- **安静时段**：默认 `23:00–09:00` 一条都不发（支持跨午夜）。
- **解耦**：完全不看「对方上次说话是什么时候」。对方今天找没找它，不影响它今天找你几次。
- **会说「隔了多久」**：开口气泡里会附一句「他上一次开口是 X 小时前」，它可以据此小小抱怨一句，也可以干脆不提；**发不发仍然与这个无关**。
- **错过不补**：固定项超过宽限 20 分钟、额外项超过 40 分钟就跳过，不会在半夜补发一串。
- **失败重试**：会话没挂起来、agent 正忙、发送抛错，都只写日志，下一分钟再试。

## 安装

```bash
dsh plugin --profile <profile> add /绝对路径/fish-clock
```

把它自己的 `cordis.patch.yml` 里那行 `insert` 挂进 profile（本包声明了 `dsh.bundle.patch`，加进 `dsh.profile.bundles` 即可）。

需要宿主提供 `agents`、`sessions`、`timer`、`webServer` 四个服务（`export const inject = ['agents', 'sessions', 'timer', 'webServer']`）。

## 装到别人的机器上（2026-11-20 加）

拿去给朋友用，按这四步：

1. **前置**：对方机器要有 DSH，并且装了 `dsh-onebot-qq`（小鱼钟靠它写的 `$DSH_HOME/media/onebot/chat-sessions.json` 找会话；没这个文件就找不到人）。
2. **放**：把整个 `fish-clock` 目录放到任意位置，比如 `D:\plugins\fish-clock`。
3. **挂**：在 profile 的 `cordis.patch.yml` 里加一条 insert（内容见包内 `cordis.patch.yml`），然后**重启 DSH**。
4. **配**：第一次跑会生成 `$DSH_HOME/fish-clock.json`，把 `会话键` 改成对方自己的 `private:<QQ号>`（群聊用 `group:<群号>`），`触发文案` 换成对方那位的人格口吻，其余时段按需改。

`$DSH_HOME` 默认是 `~/.dsh`；想放别处就设环境变量 `DSH_HOME`，或用 `FISH_CLOCK_CONFIG` 直接指定配置文件。
装完在「插件 → 已安装 → fish-clock → 详情」里能改时段、立刻试发一条、看日志。

## 设置面板

装好以后打开 **插件 → 已安装 → fish-clock → 详情**，详情里会多出一块面板（不用改 JSON、不用重启）：

- **开关**：整点停摆还是照常叫。
- **今天的表**：今天剩下的几次分别在几点、哪次已经发过（打过勾的就是发完了）。
- **每天必发的时段**：一行一个「起 → 止」，点「删掉」去掉，点「+ 再加一个时段」加一行。每段里随机挑一分钟，保证那天一定有。
- **白天再随机补几次**：补 0~3 次、允许落在哪个时间段、离必发时段至少隔多少分钟。
- **别打扰的时段**：几点到几点一条都不发，可以跨夜（23 → 9）。
- **她开口那句话**：塞进会话的内心话，具体怎么展开由模型自己决定。
- 底部「保存」按下去立即生效；「现在试一条」会立刻叫它说一句（会花一点余额，有二次确认）；「最近发生了什么」展开就是日志尾部。

面板只读写 `$DSH_HOME/fish-clock.json`，所有接口都在 `/fish-clock/state`、`/fish-clock/save`、`/fish-clock/send`，只放行本机页面（跨站请求一律 403）。
## 配置

配置文件默认 `$DSH_HOME/fish-clock.json`（`DSH_HOME` 默认 `~/.dsh`），**改完不用重启**，下一轮核表就读到新值。可以用 `FISH_CLOCK_CONFIG` 显式指定别的路径：

```json
{
  "总开关": true,
  "会话键": "private:605062555",
  "固定窗口": [["09:30", "10:00"], ["14:00", "14:30"], ["19:30", "20:00"]],
  "额外次数": [1, 2],
  "额外时段": ["09:00", "23:00"],
  "额外避开分钟": 20,
  "安静起": 23,
  "安静止": 9,
  "固定宽限分钟": 20,
  "额外宽限分钟": 40,
  "触发文案": "（心里有点别扭）该主动找他说句话了。……"
}
```

| 字段 | 含义 |
|---|---|
| `总开关` | `false` 时整点停摆 |
| `会话键` | 从 `$DSH_HOME/media/onebot/chat-sessions.json` 里按这个键取当前会话 id，`/new` 换 id 也能自动跟上（路径可用 `FISH_CLOCK_MAP` 覆盖）|
| `固定窗口` | `[起, 止]` 的 `HH:MM` 列表，每格必发一次 |
| `额外次数` | `[最少, 最多]`，例如 `[1,2]` 表示每天随机 1 或 2 次 |
| `额外时段` | 额外次数允许落下的时间范围 |
| `额外避开分钟` | 额外项离固定项至少隔多少分钟，避免连着响两次 |
| `安静起` / `安静止` | 静音时段，跨午夜写成 `起 > 止`；写相等表示不启用 |
| `固定宽限分钟` / `额外宽限分钟` | 到点后还允许迟发多久，超过就跳过 |
| `触发文案` | 塞进会话的那句「内心话」，口吻由你自己定 |

## 它到底往会话里塞了什么

一句话，但外面包了两层，好让模型明白这不是对方发来的消息：

```
（下面这句是**你自己心里冒出来的念头**，不是对方说的话；顺着它去做就行……）
（现在这会儿是 11 月 15 日 周日 上午 9:31，按这个点来想事、说话。）
（心里有点别扭）该主动找他说句话了。……
```

消息带 `source: { kind: 'fish-clock' }`，会话日志里一眼能看出哪几条不是用户打的。

错过了 09:51（固定），已经超过宽限，不补

## 已知限制

- 时刻表是「当天首次核表时」算一次并缓存在内存里，所以当天改配置只影响**还没到点且已重算**的部分；重启或插件重载会重算。
- 依赖 onebot 插件的 `chat-sessions.json` 做会话寻址，纯本地 DSH 场景需要改 `当前会话id()`。
- 设置面板在「插件 → 已安装 → fish-clock → 详情」里；改完保存即生效，不用重启。
